# 《異環》預抽卡網頁活動 (pre-gacha)

《異環》(Neverness to Everness, NTE) 雙平台預抽卡活動網頁。玩家登入後可訂製專屬「市民卡」、完成每日任務累積道具抽取次數與幸運抽獎機會，兌換遊戲內道具與實體周邊獎勵。

- 正式網址：https://nte.iwplay.com.tw/event/pre-gacha
- 活動時間：2026/3/23 上線

## 遊戲背景

《異環》是 Hotta Studio 自主研發的超自然都市開放世界 RPG。故事從海特洛市啟篇，玩家作為首位「無證工作」的「異象獵人」，加入古董店「伊波恩」接取民間異象委託，與夥伴們一起探索城市謎團。

## 活動玩法

- **主頁**：所有功能皆需先登入才能操作。
  - 主視覺下方有「市民卡訂製」「道具市集」兩個主要入口，道具市集按鈕旁即時顯示剩餘抽取次數。
  - 導覽列功能按鈕：獎勵一覽、分享（複製連結）、音樂開關、活動規則；另有「查看市民卡」「道具背包」入口。
  - 登入／登出：點擊登入圖示開啟登入彈窗；demo 階段以手機號碼＋平台選擇模擬登入成功，正式環境改走 SDK 登入彈窗。
- **市民卡訂製**：
  - 三個分類頁籤：姓名／角色、職業、卡面背景，上方即時預覽卡片（編號、職業、登記日期、取景地）。
  - 職業共 4 種：總之能解決一切的鑑定師、收容最強異象之人、(未來的)海特洛首富、米格爾區的山路車神。
  - 可一鍵「隨機」產生內容，完成後點「完成定制」跳出結果彈窗，可保存身分卡、保存分享圖、複製分享連結；首次分享市民卡可額外獲得 2 次道具抽取與 1 次幸運抽獎機會。
- **道具市集**：
  - 10 個道具格位環繞中央抽取按鈕排列，點擊抽取後以 JS 跑馬燈效果（類小瑪莉跑燈）讓高亮依順時針繞格位跑動，繞 2 圈後速度漸慢（easeOut）停在中獎格位，再對應發放道具並標記為已抽中；已抽中的格位之後不會再被抽到，直到全部抽完。
  - 右側任務列表，完成任務可獲得抽取次數：
    1. 預約《異環》 → +2 道具抽取
    2. 每日分享活動 → +1 道具抽取（每日可做一次）
    3. 完成市民卡訂製並分享 → +2 道具抽取、+1 幸運抽獎
    4. 邀請未預約過的好友成功預約 → 每人 +1 道具抽取、+1 幸運抽獎（最多累計 10 次）
- **道具背包**：以 JS 用道具名稱為 key 統計各道具的已獲得數量（`obtainedItems`），左側格位只顯示有拿到的道具並標示剩餘可選數量；點擊左側道具會移入右側「確認領取」區（`confirmSlots`，上限 6 格，額滿會彈窗提示），點擊右側已選道具可移除退回左側；數量用完的道具會標記為已選滿不可再點。最終點擊「確認領取」後綁定至遊戲帳號（第一個創建角色的信箱），確認綁定後無法再修改。
- **幸運抽獎**：另一組抽獎池，獎項與總量：PlayStation5 Pro ×2、滑鼠墊(海上列車款) ×20、角色壓克力立牌(隨機款) ×100、角色徽章(隨機款) ×200，其餘為「謝謝參與」，獎池共 20 萬份。中獎後需填寫收件姓名／電話／地址，送出後無法更改。
- **活動規則／商店預註冊**：活動規則彈窗說明活動內容與獎勵；另有「前往商店預註冊」彈窗導向各平台 Store 連結，並標示「2026-04-29 正式公測」。

## 版面規格 / RWD

- 主視覺採固定 16:9 比例版面（`aspect-ratio: 1920/1080`），由 `js/reset.js` 以 rem 做等比縮放（桌機／手機橫式以 2560px 寬為基準，對應 `css/master.css`）。
- 僅支援橫式瀏覽：當偵測為行動裝置且畫面為直式（高 > 寬）時，會切換載入 `css/master_m.css`（750px 寬為基準）並隱藏實際內容，改顯示全螢幕遮罩提示（`.note_flex`，含請旋轉裝置圖示與文字），待使用者將裝置轉為橫向後才會顯示活動頁面內容。
