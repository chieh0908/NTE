# 《異環》官方網站

《異環》(Neverness to Everness, NTE) 官方網站首頁。本次更新（260513 版本）於「角色介紹」頁籤新增角色「潯」的卡片與介紹內容。

- 正式網址：https://nte.iwplay.com.tw/

## 遊戲背景

《異環》是 Hotta Studio 自主研發的超自然都市開放世界 RPG。故事從海特洛市啟篇，玩家作為首位「無證工作」的「異象獵人」，加入古董店「伊波恩」接取民間異象委託，與夥伴們一起探索城市謎團。

## 頁面內容

- **首頁（`.pageIndex`）**：主視覺影片（PC）／靜態圖（手機），提供預告片連結、QRcode 與 iOS／Android／PC／PS5 各平台下載按鈕，側邊另有聯名活動廣告連結。
- **預約里程碑（`.pageMilestone`）**：顯示目前預約人數進度條與 5 個階段獎勵節點，並附社群分享區。
- **情報速遞（`.pageNews`）**：以新聞／遊戲新聞／遊戲公告／遊戲活動四個頁籤切換消息列表，右側附輪播廣告 Banner。
- **角色介紹（`.pageRole`）**：以頁籤式輪播切換瀏覽潯、Zero（男／女）、薄荷、娜娜莉、小吱、九原、哈索爾、白藏、法帝婭、早霧等角色，每位角色皆有 PC 版介紹影片／手機版靜態圖、角色名稱圖與角色介紹文字。
- **世界全景（`.pageView`）**：以橋間地、米格爾區、未聞浦、繪空町、新赫蘭德區等城市分區呈現，各分區皆有圖片輪播與地區介紹文字，可左右切換分區。
- **都市映像（`.pageCity`）**：城市風景圖片輪播，PC／手機各自提供對應尺寸圖源。
- **選單頁（`.page_menu`）**：漢堡選單展開後顯示導覽按鈕、登入狀態（顯示 UID 與登出按鈕）、PC 版廣告 Banner 與其他平台連結。
- **其他彈窗**：預約／登入表單（`#regressmodal`，手機號碼＋平台選擇）、預約成功（`#successmodal`／`#successmodal_dual`，含 FB／Discord 連結或雙平台下載按鈕）、隱私權政策（`#privacymodal`）、測試資訊說明（`#testinfomodal`）、通用提示（`#eventAlert`）。

## 版面規格 / RWD

- 版面由遠端 `reset.js` 依視窗寬度動態設定縮放基準，搭配 Bootstrap／Swiper 做響應式排版；多數圖片／影片皆提供 PC 與手機（`m` 資料夾）兩套圖源依裝置寬度切換，而非單一素材自適應伸縮。
