# 《異環》FF47 Coser捕捉刮刮樂活動網頁 (FF47lottery)

《異環》(Neverness to Everness, NTE) 聯動 Fancy Frontier 47 同人展的打卡刮刮樂活動網頁。玩家於展場拍攝並公開發布「異環Coser」貼文，登入遊戲帳號提交貼文網址通過審核後，即可返回活動頁刮開金色或紫色刮刮樂獎勵。

- 正式網址：https://nte.iwplay.com.tw/event/FF47lottery.html
- 活動時間：即日起 ～ 2026/08/25 23:59:59（UTC+8），FF47 場次為 8/21-8/23（花博公園爭豔館）
- 開獎時間：2026/08/31 11:00:00（UTC+8）起開放刮開獎勵

## 遊戲背景

《異環》是 Hotta Studio 自主研發的超自然都市開放世界 RPG。故事從海特洛市啟篇，玩家作為首位「無證工作」的「異象獵人」，加入古董店「伊波恩」接取民間異象委託，與夥伴們一起探索城市謎團。

## 活動玩法

- **主頁**：主視覺為一張立體刮刮卡（`.card_main`），卡面上以條列文字引導五個步驟：拍攝 Coser → 發布公開貼文 → 登入遊戲帳號 → 上傳貼文連結 → 完成後可查看獎勵品質（8/31 開放刮獎）。
  - 卡片按鈕群組：「獎勵一覽」開啟獎品蓋版、「活動規則」開啟規則彈窗。
  - 進站時主卡片與卡片前景皆以 `opacity: 0` 隱藏，待玩家關閉獎品蓋版後才觸發 `bounceIn`／`bounceInDown` 進場動畫（Animate.css），動畫結束才移除動畫 class 並啟動 3D 傾斜效果，避免 `transform` 衝突。
- **登入／打卡提交**：點擊登入按鈕後顯示網址輸入框與會員按鈕；輸入打卡網址並送出會先跳出「確認提交」彈窗，確認後顯示提交成功提示，並解除刮刮卡的透明擋板讓玩家開始刮獎。另有 SDK 登入彈窗（`#bookedmodal`）以狀態機（`initial`／`selectState`／`state1`簡訊驗證碼／`state2`密碼登入／`state3`角色選擇）管理各登入分支畫面切換，demo 階段用按鈕模擬流程。
- **審核規範／活動規則**：卡面上的「拍攝與審核規範」連結與導覽「活動規則」按鈕分別開啟對應區塊／彈窗，列出拍攝規範（需清楚辨識角色與 Coser、禁止側拍非公開狀態等）、活動介紹、金色／紫色品質獎項內容與領獎流程；點擊畫面其他區域或切換到另一區塊時會自動收合。
- **刮刮樂（核心玩法）**：
  - 以 Canvas 繪製刮除層，滑鼠／觸控拖曳即可刮開銀漆，刮除面積達 70% 時自動清空剩餘遮罩並於 0.8 秒後彈出「恭喜獲得」中獎彈窗。
  - 打卡提交成功後由 `randomizeScratchCard()` 隨機決定金漆或紫漆，金漆對應獎品編號 1~5、紫漆對應 6~9，並同步替換底層獎品圖與中獎彈窗圖片。
  - 中獎彈窗關閉後自動接續跳出「填寫收件資訊」彈窗，需完整填寫姓名／手機／Email／地址才能送出；若直接關閉彈窗而未填寫，刮刮卡上會留下一顆「填寫收件資訊」按鈕可隨時再次開啟補填。送出成功後欄位鎖定為唯讀，刮刮卡上的按鈕也會切換為「查看收件資訊」，點擊僅會開啟同一個彈窗以唯讀檢視已送出的內容，不可再修改。
- **獎勵一覽蓋版**：點擊「獎勵一覽」開啟全螢幕黑底蓋版，列出全部 9 項獎品格位；點擊蓋版空白處（非獎品區塊）關閉，並在首次關閉時觸發主卡片進場動畫。
- **其他彈窗**：登入提示（確認跳轉官網）、聯絡資料填寫、不符合資格提示、隱私權政策等。

## 核心技術實作

- **刮刮卡實作**（`js/main.js`）：以 `<canvas id="j-cvs">` 搭配 `globalCompositeOperation = "destination-out"` 實現滑鼠／觸控刮除銀漆的擦除效果；透過 `getImageData` 逐像素比對透明像素比例（`diffTransSize`），刮除達到設定門檻（70%）時自動補刮剩餘區域並觸發結算，避免玩家需要刮滿 100% 才能看到結果。圖片皆設定 `crossOrigin = "anonymous"` 以避免 canvas 被跨網域圖片污染。
- **刮刮卡掃光特效**（`css/master.css`）：在 `.scratch_box::after` 疊一層帶 `skewX(-25deg)` 斜角的白色漸層光束，以 `sweepLight` keyframes 每 4 秒無限循環從左掃到右，暗示銀漆可刮；玩家開始刮卡時加上 `.is-scratching` class 隱藏該光束，避免跟刮除動作互相干擾，刮完結算後再移除 class 讓光束恢復循環。
- **3D 傾斜效果**（Vanilla-Tilt，`TiltEffectManager`）：獨立模組包裝 `VanillaTilt.init/destroy`，掛載於 `.card_main` 卡片上（`max: 2`、`speed: 1000`、關閉反光），並暴露 `window.initVanillaTilt`／`window.destroyVanillaTilt` 供 `demo.js` 與進場動畫流程呼叫；刮卡前先銷毀特效避免影響刮除座標判斷，露出獎品圖與進場動畫跑完後才重新啟用，讓立體感只出現在不影響操作的時機。
- **獎勵清單跑馬燈（互動拖曳／滑動）**（`initUniversalMarquee`）：
  - 將原始獎品清單複製兩份首尾相接，以 `requestAnimationFrame` 依容器排版方向（橫向／直向）自動計算速度並用 `translate3d` 平移，形成無限循環跑馬燈；視窗縮放或裝置旋轉時以 `ResizeObserver` 重新量測並重置位置。
  - 新增滑鼠／觸控拖曳控制（`mousedown/touchstart` → `mousemove/touchmove` → `mouseup/touchend`，綁定於 `window` 確保拖曳超出邊界仍可更新），拖曳時暫停自動滾動並依位移量即時更新位置，鬆手後恢復自動跑動；滑鼠移入時（非行動裝置）暫停自動滾動，方便玩家細看獎品。
- **RWD／版面縮放**（`js/reset.js`）：不論 PC 或手機，活動頁面本身只有一套橫式版面（`css/master.css`，2560×1440 為基準），以 rem 做等比縮放；當偵測為行動裝置且畫面為直式（高 > 寬）時，才切換載入 `css/master_m.css` 蓋過整個畫面（僅含黑底全螢幕遮罩樣式，非另一套直式排版），隱藏主要內容並顯示「請旋轉裝置」提示，待玩家將裝置轉為橫向後才切回 `master.css` 顯示實際活動內容。
- **彈窗流程管理**：以 Bootstrap Modal 搭配多個狀態旗標（`isInfoSubmitted`、`hasCardAnimated`、`currentState` 等）串接「刮獎 → 填寫收件資訊」「打卡確認 → 提交成功 → 解鎖刮獎」等多層彈窗的開關順序；另修正多重彈窗疊加時，最新產生的 `.modal-backdrop` 需動態調整 `z-index` 才不會被前一層蓋住。

## 版面規格 / RWD

- PC 與手機共用同一套固定比例橫式版面（`css/master.css`，2560×1440 基準），由 `js/reset.js` 以 rem 做等比縮放；
- 僅支援橫式瀏覽：當偵測為行動裝置且畫面為直式（高 > 寬）時，載入 `css/master_m.css` 顯示全螢幕黑底遮罩與「請旋轉裝置」提示並隱藏實際內容，待玩家將裝置轉為橫向後，才切回 `master.css` 顯示活動頁面內容。
