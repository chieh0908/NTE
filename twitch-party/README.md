# 《異環》1.5版本 Twitch 實況觀賞派對活動網頁 (twitch-party)

《異環》(Neverness to Everness, NTE) 1.5 版本Twitch 實況觀賞派對活動網頁。玩家登入遊戲帳號後，透過本頁前往不同 Twitch 直播間觀看直播，達成指定觀看任務次數即可領取環石、方斯等養成獎勵；活動分為首日與次日兩輪任務，完成首日任務後次日才會開放。

- 正式網址：https://nte.iwplay.com.tw/event/twitch-party.html
- 活動時間：2026/11/11 10:00 ～ 2026/12/1 23:59（UTC+8）

## 遊戲背景

《異環》是 Hotta Studio 自主研發的超自然都市開放世界 RPG。故事從海特洛市啟篇，玩家作為首位「無證工作」的「異象獵人」，加入古董店「伊波恩」接取民間異象委託，與夥伴們一起探索城市謎團。

## 活動玩法

- **版頭（header）**：主視覺搭配活動標題與兩顆導覽按鈕──「查看任務」錨點捲動至任務區塊、「觀看直播」錨點捲動至直播列表區塊。
- **完成任務獲得獎勵（`.mission`）**：提供「活動規則」「帳號登入」兩顆按鈕，登入後「登入」按鈕會切換為「登出」；區塊內分為首日／次日兩組觀看任務卡片，各自顯示「觀看任務進度：0/6」，達成次數後可點擊領取，次日任務需完成首日任務後於隔日 00:00 才會開放。
- **Twitch 直播列表（`.streams`）**：列出繁體中文／所有語言兩個分類的直播卡片（含封面、觀看人數、標題、實況主名稱），手機版可透過頁籤切換語言分類；「查看更多」導向《異環》Twitch 分類頁。
- **其他彈窗**：活動規則（`#notice_modal`）、通用提示（`#eventAlertModal`，如提示請先登入帳號）、SDK 登入彈窗（`#bookedmodal`）、隱私權政策（`#privacymodal`）。

## 版面規格 / RWD

- 版面以 `vw` 彈性字體撐滿版面，搭配 Bootstrap 風格中斷點（1200px／820px／768px，768px 橫式另有專用微調）做結構調整，沒有 rem 等比縮放或裝置偵測切換樣式表的機制，也沒有強制橫式瀏覽的設計。
