# 《異環》伊波恩合夥人行動活動網頁 (EibonPartner)

《異環》(Neverness to Everness, NTE) 1.2 版本「九百九十九夜」回流活動網頁。活躍鑒定師可生成專屬邀請碼邀請回歸鑒定師重返遊戲，雙方透過完成合夥人任務與幸運抽取獲取環石等獎勵。

- 正式網址：https://nte.iwplay.com.tw/event/EibonPartner.html
- 活動時間：1.2 版本更新後 ～ 2026/08/18 03:59:59（UTC+8）

## 遊戲背景

《異環》是 Hotta Studio 自主研發的超自然都市開放世界 RPG。故事從海特洛市啟篇，玩家作為首位「無證工作」的「異象獵人」，加入古董店「伊波恩」接取民間異象委託，與夥伴們一起探索城市謎團。

## 活動玩法

- **首頁（event_home）**：顯示活動主視覺與信封動畫，提供活動規則、前往商店預註冊、會員資訊等入口；點擊「登錄」導向 SDK 登入彈窗，依帳號狀態分流至下列兩種頁面。
- **合夥人行動頁（event_partner_action，活躍鑒定師視角）**：
  - 頂部顯示個人專屬邀請碼，可一鍵複製或分享連結。
  - **合夥人任務**：首次／每日分享專屬連結，以及成功召回 1／2／3／5 位回歸鑒定師，最高可累計獲得環石×360（另有分享獎勵環石×40、甲硬幣×10000／日）。
  - **幸運抽取**：5 張卡片翻牌抽獎，抽取次數由邀請回歸鑒定師累積（最多 5 次），單抽最高環石×320，5 抽必得環石×480＋新銳獵人攻略×3＋甲硬幣×1500。
  - 「邀請狀態」彈窗可查看已邀請用戶 UID 與回歸進度（成功回歸／需遊戲內解鎖）。
- **受邀人簽屬頁（event_invitee_signing，回歸鑒定師視角）**：
  - 進站時彈出「初始簽署彈窗」，需輸入專屬邀請碼完成綁定，或選擇不綁定；確認綁定後彈窗關閉，輸入的邀請碼會同步帶入受邀人簽屬頁主畫面的邀請碼輸入框（切換為已確認狀態的唯讀文字）。
  - 綁定前任務列表／幸運抽取區域由遮罩（`.signing_overlay`）覆蓋，提示下載遊戲或登入解鎖；完成綁定並登入遊戲後彈出「成功回歸獎勵」，取得自己的專屬邀請碼，之後亦可反向邀請其他鑒定師回歸。
- **登入／登出**：SDK 登入彈窗支援手機號碼＋驗證碼（含圖形驗證碼）、第三方快速登入（Google／iOS／Facebook／PlayStation）與多角色選擇；demo 階段可用右下角「切換」浮動按鈕（`.demo_switch_btn`）在首頁／合夥人行動頁／受邀人簽屬頁三種狀態間手動切換測試。
- **其他彈窗**：活動規則、恭喜獲得獎勵、下載區（各平台 Store 連結＋QR Code）、隱私權政策。

## 核心邏輯（`js/main.js`）

- **`switchPage(targetClass)`**：全站頁面切換的單一入口。隱藏所有 `.event` 頁面並顯示目標頁面，依目標頁面決定是否顯示 demo 用的「切換」浮動按鈕與 footer；另外控制受邀人簽屬頁的「初始簽署彈窗」只在切換到該頁、且尚未被手動關閉過時才顯示。首頁「登錄」按鈕與 demo 切換按鈕皆呼叫此函式切換頁面。
- **合夥人行動的頁籤切換**：點擊 `.partner_tab` 時，在同一 `.event` 容器內移除其他頁籤的 `active`、淡入對應 `data-target` 的 `.tab_content`（合夥人任務／幸運抽取），並依目前頁籤決定任務備註文字（`.task_note`）是否顯示；合夥人行動頁與受邀人簽屬頁各自有一套獨立頁籤與內容區塊，共用同一段綁定邏輯。
- **幸運抽取 3D 動畫與洗牌特效**：
  1. 點擊抽取後隨機挑一張卡片翻牌（`.is-flipped`），獎品從 `availableGifts` 陣列中隨機抽出並移除，確保 5 個獎項不重複；以 `isAnimating` 旗標鎖定期間的重複點擊。
  2. 翻牌後依序觸發兩段彈窗：先以卡牌背面圖顯示「展示獎勵」彈窗（1.5 秒後自動或點擊提前進入下一步），再換成 `#popGetAward` 的「獲得獎勵」彈窗。
  3. `#popGetAward` 關閉後執行 `closeModalAndShuffle` → `executeShuffle`：卡片蓋回背面，再用 `getBoundingClientRect` 計算各卡牌與牌堆中心的偏移量，使所有卡片飛向中心並疊加隨機旋轉角度模擬洗牌，停留 0.8 秒後歸位回原本格位，動畫結束才解鎖 `isAnimating` 讓玩家進行下一次抽取。

## 版面規格 / RWD

- 主視覺採固定比例版面，由 `js/reset.js` 以 rem 做等比縮放（桌機／手機橫式以 2560px 寬為基準，對應 `css/master.css`）。
- 僅支援橫式瀏覽：當偵測為行動裝置且畫面為直式（高 > 寬）時，會切換載入 `css/master_m.css`（750px 寬為基準）並隱藏實際內容，改顯示全螢幕遮罩提示（`.note_flex`，含請旋轉裝置圖示與文字），待使用者將裝置轉為橫向後才會顯示活動頁面內容。
